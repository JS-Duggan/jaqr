# JAQR, Silent R Language (aka Step)

## Tools

- CMake
- Ninja
- Just
- C++20 Compiler
- clang-format
- clang-tidy

## Commands

- `just` — build (debug)
- `just run` — build and run
- `just release` — build (release)
- `just format` / `just format-check` — format / check formatting
- `just lint` — run clang-tidy
- `just clean` — remove build files
